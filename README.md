# MotoGP Stats

Primer esqueleto visual de una aplicación de estadísticas de MotoGP.

## Stack
- Node.js
- TypeScript
- Next.js
- React
- Tailwind CSS
- Lucide React

## Ejecutar
```bash
npm install
npm run dev
```

La primera fase utiliza datos de ejemplo. La siguiente fase conectará los servicios Node.js con la API de MotoGP.
